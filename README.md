# Учебная практика

## Название сайта: **MyNEWS** 

**Основная задача сайта:**
Показывать пользователю новости из разных источников, и в случае выбора перекидывать его на оригинал. Есть возможность добавить какую-либо статью в "Список" где он сохраняется и пользователь может позже верунться и проситать.

----

## Как скачать
git clone https://github.com/MoonMint0-0/my-news-app.git
cd my-news-app

# Установить зависимости
npm install

# Запустить
node index.js

Открой: http://localhost:8080
